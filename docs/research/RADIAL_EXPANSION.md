# Connected branches and exact field details

The graph expands in place. Its twelve main workflow boxes and their fifteen directed dependencies remain in the same network while detailed branches are opened. Opening another branch does not replace the first one. The current default organizes the network as a top-to-bottom road with stage-owned side bays; see ROADMAP_LAYOUT.md. The earlier radial arrangement is historical. Placement is a reading aid, not a research result.

Main boxes expose the existing section's specific parts. A category can fold or unfold its recorded descendants. A detailed part can reveal exact source fields such as its formula/rule, declared inputs and outputs, linked variable definition and code-component names. These field annotations carry their owner and source field; they are display detail, not newly collected data or additional scientific variables. Shared canonical definitions and code symbols use stable identities rather than copies for every owner.

The reviewed catalog contains 303 workflow parts, including 76 categories and 227 leaves. Section sizes vary: Market observations has 20 parts, Features & universe 45, Return & risk model 64, and the other nine sections have 16–32 each. The separate legacy variable catalog has 59 definitions. The detail catalog supplies 67 exact formula fields and 30 unique component names; these are not 100 independent predictive features per main box.

## Connections and provenance

The viewer preserves the fifteen main workflow dependencies and 454 curated detailed relationships. The catalog also contains 182 explicit `wd:` references in its input/output lists. These resolve to 112 directed endpoint pairs. Seventy-six pairs already have curated relationships; their reference provenance can be attached without drawing duplicates. The remaining 36 pairs are additional display connections derived from recorded fields, including 26 cross-stage pairs.

A declared input points from the referenced part to the owner. A declared output points from the owner to the referenced part. Only a complete string exactly matching an existing part ID qualifies; prose is not parsed into new assertions. Derived connections retain owner ID, field name and index, and distinguish one-sided from two-sided declarations. An input/output reference is a documentary dependency, not evidence of causal influence, predictive skill or a working daily integration.

Main-box membership and field-annotation links are structural navigation links. They are distinct from curated assertions and do not increase the canonical 303-part or 454-assertion totals. A definition, formula or legacy measurement remains subject to its recorded scope and readiness; displaying it does not adopt it into a predictive schema.

## Navigation

Open several main boxes to compare their detailed branches. Select a specific part to inspect its full source-backed explanation. Use the branch-focus control to frame an open branch and Fit network to see the wider context. Collapse controls fold a branch without replacing the rest of the network. Dragging changes placement and keeps attached links; it does not open another branch or edit source records.

The reading view and native record picker remain available. Node placement, folded groups and field expansion are page-session presentation state. Open main-branch IDs can also be retained in the URL for returning to the network. These controls do not edit GitHub, Neo4j or Notion. The five public data JSON files remain unchanged. No model, data collection, backtest or brokerage connection is run by this graph.

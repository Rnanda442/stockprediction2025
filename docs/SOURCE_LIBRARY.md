## Source Use Rules

- Research sources inform hypotheses and test design; they do not automatically become
  production requirements.
- Record each source's data domain, date, assumptions, and limitations.
- Prefer primary papers and official API documentation.
- Do not promote a model based only on a published ranking. Reproduce the comparison using
  this app's horizons, data, costs, and walk-forward evaluation.
